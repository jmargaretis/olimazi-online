closest to reckon.house

This is the one that reads as an object on a table rather than a panel in a layout.

Rental Manager · what makes it read as old

part two

Three specific things, not a vague vibe. One: the checkboxes are a text character (☐ set at 21px), not a control — that alone dates it a decade. Two: every element carries a 1px tan border, so nothing has hierarchy; borders are doing work that spacing and background should do. Three: the palette is Heritage — cream #F4EDDD, crimson #9B1C2E, olive #566123, sand #D2C8B0 — and the site moved to sage months ago, so the product and the page selling it look like two different companies.
